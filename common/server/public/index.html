关于 ScrcpyNas

          

            
          

        

        

          

            

              
套件用途

              
在局域网中连接 Android 设备，并通过浏览器进行实时投屏和触摸控制。

            

            

              
使用方式

              
先在手机开启无线调试，再点“连接设备”填写 IP 与端口；连接成功后左侧会保存记录，单击记录即可打开投屏。
